## 4837 是联通骨干，不是 9929，也不是 CN2 GIA

这里有两个几乎每次都会被问到的混淆点。

**第一，AS4837 不等于 AS9929。** 9929 是联通的 CUII 精品网，回国延迟更低、晚高峰更稳，代价是带宽通常 50Mbps 封顶，价格贵一截。4837 走的是联通骨干，带宽动辄 300Mbps 起步，价格便宜，两者回国延迟大概差 20–40ms。这 20–40ms 在网页、视频、后台操作里几乎感觉不到，在游戏和远程桌面里就是能不能玩下去的区别。

**第二，“三网4837”不是只服务联通用户。** 它指的是把电信、联通、移动三家的回程都强制切到联通 AS4837。电信和移动用户走的其实是“借联通骨干回国”这条路——听着绕，实际晚高峰往往比挤自己运营商的普通国际出口还稳。这也是这类机器在中文圈能一直有搜索量的原因：它解决的不是“联通用户怎么办”，而是“三网用户晚高峰都难受”。

判断句可以很简单：要延迟最低、跑游戏加速或远程桌面，选 9929 或 CN2 GIA；要带宽和流量、跑运营和流媒体，4837 更划算。同时把预期摆正——4837 的优势是晚高峰稳定不丢包，不是延迟低。别拿它跟香港、日本机房的 30–70ms 比。

## 三网回程到底怎么走，180–215ms 是什么水平

这部分不靠官方宣传，看第三方测评里抓到的路由。

**联通回程最干净**：洛杉矶直上 AS4837，一路联通骨干到广州、上海、北京，全程不绕路。本机是联通宽带的话，这条线路在三个运营商里体验最好。

**电信回程**：洛杉矶机房先到联通美西 POP（AS10099），经香港联通中转，再上联通骨干 AS4837 到北京，最后由电信 AS4134 / AS23724 落地。走的是“借联通骨干回国”，不是电信自己的 163。

**移动回程**：路径和电信类似，经联通美西 POP 和香港联通，再走 AS4837，最后由移动 AS56040 / AS9808 落地；去程是移动 CMI 直连美西。

延迟上，第三方测评里电信和移动回程的国内节点普遍落在 180–215ms 区间，联通略低。这是美西机房加 4837 回国的正常水平，不要指望它跟香港、日本机房比。去程各家运营商走自己的骨干直连美西，和普通美西机房差别不大——你花钱买的其实是回程这一段。

**哪些人不该买 4837**：要 30–70ms 延迟的；打游戏、跑远程桌面这类对延迟敏感的；要求晚高峰绝对零波动的。4837 是共享线路，国内晚间 20:00 到 22:00 出现波动是正常现象，对这个不能接受就应该直接看 9929 或 CN2 GIA。

## IP 质量：双 ISP 家宽住宅 IP 才是这套机器的差异点

带宽和价格是可以横向比较的，IP 属性不行。

丽萨主机这套默认分配的是**双 ISP 家宽住宅美国原生 IP**：IP 注册信息指向两家美国本土 ISP，多个 IP 数据库把它识别为 ISP / 家宽，而不是 datacenter。这个区别对普通上网毫无意义，但对会校验 IP 类型的服务就是门槛——TikTok 的风控、OpenAI 的访问限制、Netflix 和 Disney+ 的美区解锁、亚马逊和独立站的后台，家宽 IP 的通过率普遍比机房 IP 高一档。

第三方测评里比较一致的观察是：ipinfo、ip2location、ipregistry 识别为 ISP / 家宽；scamalytics 欺诈分为 low，abuse 得分为 0；没有被标记成 proxy / VPN / Tor 出口；TikTok、Netflix、Disney+、ChatGPT 在样本测试中都能解锁。**端口 25 是关闭的**，想拿它发邮件基本没戏，这点和绝大多数 VPS 一样。

必须提醒的是，IP 段会轮换，不同批次拿到的 IP 表现有差异，没有人能保证某个 IP 永久全绿。拿到机器后第一时间用 `region-check`、`media-unlock` 这类脚本跑一遍，比看十篇评测都准。如果原 IP 被风控了，官方还提供每月加 20 元更换纯净新 IP 段的选项，这个价格放在“账号比机器贵”的场景里不算贵。

## 几个必须先知道的限制

**退款不是无条件的“无条件”。** 标准套餐页面都标了 48 小时不满意无条件退款，但服务条款里有一条容易被忽略：48 小时内使用超过分配带宽的 5% 或 20GB（取较小值），不符合退款条件。翻译过来就是——先跑爆流量再申请退款，可能退不了。拿到机器先小流量测，确认没问题再上业务。

**特价年付版和 VDS 类产品的退款规则，页面表述不一致。** 官方产品页标的是 48 小时无条件退款，但另有资料称这类特价产品和静态住宅 IP VDS 只退网站余额。下单前在订单页把规则看清楚，不要按“肯定能原路退款”来规划。

**1Gbps 在晚高峰跑不满是常态。** 带宽标称值和你实际能跑到的速度之间隔着本地宽带、运营商互联和骨干负载三层，任何一家 VPS 都一样。

**IP 解锁能力会变。** 今天能解 Netflix 的 IP 段，几个月后可能就不行了。做账号运营的，把 IP 当成消耗品而不是固定资产来规划预算。

**不限流量有公平使用原则。** 长时间满带宽传输，商家有权介入，这是行业惯例，不是这一家的特别条款。

**25 端口关闭。** 需要发信的業務从一开始就要另想办法。
